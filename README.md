# sierpinski-triangle-generator
Python script that interactively generates the Sierpinski triangle fractal

## How To Make It Work
1. Run the script. A window will open.
2. You are about to use mouse-clicks to define points on the plane.  Click your mouse ***three times*** somewhere on the screen to define three non-collinear points.  These serve as the vertices of your base triangle.
3. Click your mouse ***a fourth time** anywhere inside (or outside) the triangle.
4. Watch as Sierpinski's triangle materializes on your screen!

## Requirements
-Python 3.x
-'pygame' library
-'random' library (built-in standard library)
